# Rocker assets

`rocker-wsl.png` and `rocker-vm.png` are transparent PNG resources generated from the two original HyperSwitch interface references.

- `rocker-wsl.png`: blue WSL side pressed; white VM side raised.
- `rocker-vm.png`: blue WSL side raised; white VM side pressed.

The application embeds both files as WPF resources and switches between them when the corresponding radio-button hit area is selected.

## Generation specifications

1. Create an isolated premium 3D two-position rocker with a graphite metallic housing, blue left key with a white penguin icon, pearl-white right key with a gray monitor-and-cube icon, cool studio lighting and a genuinely transparent background. No text, surrounding window, badges or watermark.
2. Preserve the first asset's housing, camera, crop, materials, colors, icons and transparency while changing only the physical rocker position: lower the blue left key and raise the white right key.
